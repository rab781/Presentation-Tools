# Commands Reference

This document provides a complete list of all available hand gestures, voice commands, and keyboard controls for the Presentation Control Tool.

## Hand Gestures

Ensure you are standing 0.5 to 2 meters from the webcam and that your hand is clearly visible in the frame.

| Gesture | Command | Action |
|---------|---------|--------|
| 👉 Swipe Right | Next | Next slide |
| 👈 Swipe Left | Previous | Previous slide |
| ✋ Open Palm | Pause | Pause/Blackout |
| ✊ Closed Fist | Play | Resume |
| 👍 Thumbs Up | First | First slide |
| 👎 Thumbs Down | Last | Last slide |
| ✌️ Peace Sign | Blackout | Black screen |

## Voice Commands

You can use either English or Indonesian commands.

### English Commands

-   **Navigation**: "next", "previous", "back", "first", "last", "start", "end"
-   **Control**: "pause", "stop", "play", "resume", "exit", "quit"

### Indonesian Commands

-   **Navigation**: "lanjut", "berikutnya", "kembali", "sebelumnya", "pertama", "terakhir"
-   **Control**: "berhenti", "jeda", "lanjutkan", "mulai", "keluar"

## Keyboard Controls

While the application is running, you can press these keys while the application window is active to control the tool's behavior:

| Key | Function |
|-----|----------|
| **G** | Switch to Gesture Only mode |
| **V** | Switch to Voice Only mode |
| **H** | Switch to Hybrid mode (default) |
| **C** | Run calibration wizard |
| **A** | Auto-detect active application manually |
| **P** | Pause/Resume detection |
| **ESC** | Exit application |
